# Matplotlib Practice

A single Python script of Matplotlib exercises I wrote while learning data visualization.

## What's Covered

`practice matplot.py` has one section for each of these chart types and features:

- Line plots and multiple lines
- Scatter plots with colormaps and colorbars
- Bar, horizontal bar, and pie charts
- Histograms and box plots
- Subplots and multi-plot figures
- Twin axes
- Grids, figure size, and axis limits
- Saving a figure (`plt.savefig`)
- Built-in style sheets

## How to Run

Each exercise is kept inside a triple-quoted string block, so running the file as it is shows nothing. To try an exercise, remove the quotes around that one section and run:

```bash
pip install matplotlib
python "practice matplot.py"
```
